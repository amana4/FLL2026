# Research

Judges want **multiple kinds** of sources — and at minimum, real conversations
with real people. Web-only research caps the score.

## Where our bee counts live

Every count sent from the [field log](field-log.html) lands in one Google Sheet,
with the photos in a Drive folder beside it. That sheet is the raw data behind
every number in this document.

Both are **Restricted**, not public, because the sheet carries first names and the
photos are of our gardens. Ask the coach for access. The links are in
`docs/team-links.md` in the repo, which is kept off this website.

| Column | What it is |
| --- | --- |
| `submitted_at` | When it was sent, which is not the same as when it was counted |
| `date`, `time_seen` | When the count actually happened |
| `observer`, `recorder` | Who watched and who typed. First names |
| `start_temp_F`, `start_wind_mph`, `sky` | The weather check. A count without these cannot be compared |
| `visitor_type`, `bee_group`, `bee_subgroup` | The pile it went in |
| `count` | How many of that type |
| `plant` | What it was feeding on |
| `photo` | A link to the picture in Drive |

**Sort by `date`, not `submitted_at`.** They differ whenever somebody sends a
count the next morning, and the count date is the one the experiment runs on.

When you write a number into this page, say which rows it came from. A judge who
asks "how do you know" should get a sheet, not a memory.
