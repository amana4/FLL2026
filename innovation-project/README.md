# Innovation Project

Find a real problem in the BIGGLOW theme, design a better solution, and share it
with people who can use it.

**This is 25% of the Champion's Award.** Start it in week 3, not week 18.

| File | What's in it |
| --- | --- |
| [`problem.md`](problem.md) | The problem we chose and why it matters |
| [`research.md`](research.md) | Sources, interviews, existing solutions |
| [`solution.md`](solution.md) | What we designed |
| [`sharing.md`](sharing.md) | Who we shared with and what they said |
| [`presentation/`](presentation/) | The 5-minute pitch |

## The five steps judges score

1. **Identify** — a clear, well-defined problem within the season theme
2. **Research** — from multiple sources, **including talking to real people**
3. **Innovate** — a solution that's genuinely ours, not copied
4. **Iterate** — we shared it, got feedback, and **changed it as a result**
5. **Communicate** — we explained it clearly and shared it beyond our team

## Where teams lose points

Worth reading before you start — these are the recurring gaps:

- **No original research.** Ten websites is not research. Judges want to hear
  "we interviewed a nurse / a farmer / a city engineer and they told us…"
- **No iteration.** Presenting v1 with no evidence anything changed loses the
  whole Iterate criterion. Document the version that got rejected.
- **Not shared.** "We'll share it someday" scores nothing. Share it — with an
  expert, a class, a community group — before the tournament.
- **Solution isn't innovative.** If it already exists exactly as described, the
  innovation has to be in *our* twist. Say what that twist is.
- **Only one student talks.** Judges notice. Everyone presents a part.
