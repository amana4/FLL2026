# Core Values

> **Discovery · Innovation · Impact · Inclusion · Teamwork · Fun**

Core Values are judged, and they're judged *everywhere* — in the judging room, at
the robot table, in the pit, in how we treat the team next to us. There's no
separate "Core Values activity" to cram for.

| File | What's in it |
| --- | --- |
| [`team-agreement.md`](team-agreement.md) | How we agree to work together |
| [`evidence-log.md`](evidence-log.md) | Specific moments that show each value |

## The six values, concretely

| Value | What it looks like in practice |
| --- | --- |
| **Discovery** | We explored new skills and ideas, including ones outside our comfort zone |
| **Innovation** | We were creative and persistent — we kept going when the first idea failed |
| **Impact** | What we learned actually gets applied to a real problem |
| **Inclusion** | Everyone is respected and included; different strengths are used |
| **Teamwork** | We're stronger together than as individuals; we share the work |
| **Fun** | We enjoy this and celebrate what we do |

Plus the two behaviours that run through everything:

- **Gracious Professionalism®** — compete hard, treat everyone with respect
- **Coopertition®** — help other teams even while competing against them

## Why the evidence log matters

Judges ask "tell me about a time your team disagreed" or "how did you include
everyone?" A team that answers with a **specific story** scores far higher than a
team that answers with a definition. Nobody remembers specifics in March from
September — so write them down as they happen.

Add to [`evidence-log.md`](evidence-log.md) at every meeting. It takes two minutes.

## Ideas that build Core Values evidence

- Bring spare parts to the tournament and lend them to a team that's stuck
- Invite a rookie team to practice against us
- Rotate roles deliberately so nobody is stuck on one job all season
- Explicitly celebrate a failure that taught us something
- Give someone quieter the lead on a section of the presentation
