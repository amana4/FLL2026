# Meeting Notes

One file per meeting, named `YYYY-MM-DD.md`. Copy [`_TEMPLATE.md`](_TEMPLATE.md).

Date-first naming means they sort chronologically on their own.

## Why we bother

1. Whoever missed the session can catch up without asking.
2. The Engineering Notebook is written from these.
3. Judges ask "how did you decide X?" and the answer is in here.
4. In February, nobody remembers what happened in October.

Five minutes at the end of each session. Assign it to someone as a rotating job.
