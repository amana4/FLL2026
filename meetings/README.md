# Meeting Logs

What actually happened, one file per meeting, named by date. All 26 files already
exist — **open the one for today and type into it**. No copying, no renaming.

The record matters for three reasons: whoever missed a session can catch up, the
Engineering Notebook is assembled from these, and judges ask "how did you decide
that?" — the answer lives here.

Five minutes at the end of each session. Rotate whose job it is.

## Plan versus record

| | |
| --- | --- |
| [`plan/`](plan/README.md) | What we intend to do, written in advance |
| this folder | What happened, written on the day |

The link between them is the **Carry forward** table at the bottom of each log,
which feeds the **Carried over** section at the top of the next plan page. Fill it
in even when it is empty — especially then.
