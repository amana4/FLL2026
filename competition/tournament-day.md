# Tournament Day

Print this. Tick things off. Nobody's memory works well at 7am in a loud gym.

## The night before

- [ ] Every hub and spare battery charged
- [ ] Programs loaded in match order and **tested on the hub**
- [ ] Robot and attachments packed in the order we'll need them
- [ ] Notebook printed / submitted
- [ ] Presentation materials and prototype packed
- [ ] [`packing-list.md`](packing-list.md) fully worked through
- [ ] Everyone knows the address, arrival time, and what to wear
- [ ] Sleep

## Arrival

- [ ] Check in at registration
- [ ] Find our pit table and set up
- [ ] Locate: practice tables, judging rooms, competition tables, toilets
- [ ] **Robot inspection** — do it early, not at the last minute
- [ ] Read the schedule; write our times on the board at our pit

There is **one** judging session, not three. It covers the Innovation Project and
Robot Design in the same 30-minute visit, and Core Values is scored through both.
Full timings in [`../docs/judging/README.md`](../docs/judging/README.md).

All five students must attend the judging session and be present at the matches —
that is an official participation rule, not a preference.

## Before each match

- [ ] Hub charged and on
- [ ] Correct program selected, ready in slot
- [ ] Attachments laid out in run order
- [ ] Robot in the launch position, gyro settled
- [ ] Everyone knows their job for this match
- [ ] Breathe

## After each match

- [ ] Score recorded in [`../robot-game/scoring-tracker.md`](../robot-game/scoring-tracker.md)
- [ ] What went wrong? Write it down before you forget
- [ ] Fix only what's clearly broken — **don't redesign between matches**
- [ ] Recharge

## Before each judging session

- [ ] Right materials in hand
- [ ] Everyone knows their speaking part
- [ ] Arrive early
- [ ] Deep breath, and remember judges want us to do well

## Things that go wrong, and what to do

| Problem | Response |
| --- | --- |
| Hub won't connect | Restart hub, then restart laptop. Try the backup cable. |
| Program missing from hub | Reload from `code/spike-projects/` |
| Attachment breaks | Spare parts box; fix between matches, not during |
| Robot fails inspection | Ask the inspector exactly what's wrong; usually it's size |
| Someone is upset | Step away from the pit together. It's a Saturday, not a career. |
| Running late for judging | Tell a volunteer immediately — they can usually help |

## Gracious Professionalism on the day

- Help the team next to us if they're struggling
- Applaud other teams' good runs
- Thank the volunteers and referees — all unpaid
- Lose well and win quietly

## At the end

- [ ] Pack everything; check under the table
- [ ] Thank the organisers
- [ ] Team photo
- [ ] Note first impressions for [`../docs/retrospective.md`](../docs/retrospective.md)
