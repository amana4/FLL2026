# Official BIOGLOW Materials

**Nothing in this repo overrides these documents.** If our notes disagree with the
official rulebook, the rulebook wins — always. When you find a conflict, fix our
notes and mention it at the next meeting.

Every file is linked below. GitHub renders PDFs in the browser, so you can read any
of them from a phone at the practice table without downloading anything. The
originals are also in `docs/official-materials/` in your checkout.

Source for all of it:
<https://www.firstinspires.org/resources/library/fll/season-materials>

## Why these are committed

By a team decision on 9 August, FIRST's materials are tracked in git so that a
clone gets everything instead of each person re-downloading. They are excluded from
the *website* build only to keep the deploy artifact small, which is why the links
above point at GitHub rather than at pages on this site.

Two consequences. This repo is public, so FIRST's copyrighted material is publicly
visible — a deliberate choice, not an accident. And committed binaries live in git
history permanently, so removing them later means a history rewrite.

**Do not run `git rm` on them.** An earlier version of this page claimed they were
gitignored and that CI would block them. Both were wrong, and following that advice
would have deleted the team's materials.

## What is deliberately not here

- **The missions video** (1.4 GB) exceeds GitHub's 100 MB per-file limit, so the
  push would be rejected. Stream it from the Season Resources page instead.
- **Purchase paperwork.** A sales order carries a billing name and a residential
  address. `.gitignore` blocks `SalesOrd*` and anything matching invoice or
  receipt. Keep receipts outside the repo.

## Extracting text from a PDF

Open them in Preview, or click the links above. To quote exact scoring wording
there is a small tool in the repo:

```bash
# Build once
swiftc -O tools/pdftext.swift -o /tmp/pdftext

# Whole document, or a page range
/tmp/pdftext docs/official-materials/fll-challenge-bioglow-rgr.pdf
/tmp/pdftext docs/official-materials/fll-challenge-bioglow-rgr.pdf 9 12
```

It uses macOS PDFKit, so nothing needs installing and it works offline. It cannot
read image-only PDFs such as the building instructions, because there is no OCR.
