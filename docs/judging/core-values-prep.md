## During the session

- Let quieter teammates answer first on questions they're comfortable with.
- Don't interrupt each other — judges watch this closely.
- If someone's stuck, it's fine to say "do you want to add to that?" — supporting
  each other *is* the thing being scored.
- Answer honestly. Rehearsed-sounding answers land worse than real ones.

## All season, not just tournament day
