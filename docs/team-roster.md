## Roles

Not fixed jobs, just a starting point so nobody sits idle.

- **Robot builders** — chassis, attachments, durability
- **Programmers** — run programs, reusable blocks, tuning
- **Project researchers** — interviews, research, solution design
- **Presenters** — Innovation Project delivery. The whole team presents; these
  students lead.
- **Notebook keeper** — makes sure meetings get logged and the notebook stays current
- **Field manager** — mat, models, spare parts, battery charging

FIRST also suggests its own six roles in the Team Meeting Guide: Team Captain,
Creative Designer, Researcher, Communicator, Project Manager, and Material
Manager. Use whichever set the team prefers.
