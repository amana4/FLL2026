# Glossary

FLL has a lot of jargon. New team members and parents can start here.

| Term | Meaning |
| --- | --- |
| **Base** / Home | The marked area on the mat where the robot starts and where you may legally touch it. Also called Launch Area. |
| **Launch** | Starting the robot from Base. |
| **Interruption** | Touching the robot outside Base. Usually costs a penalty and you must return it to Base. |
| **Precision Tokens** | Tokens you start the match with; you lose one each time you interrupt the robot. Remaining tokens are worth points. _Verify the exact count and value in the BIOGLOW rulebook._ |
| **Mission** | One scoring task on the field. |
| **Mission Model** | The LEGO structure on the mat that a mission uses. |
| **Run** | One trip out from Base and back, usually completing several missions. |
| **Attachment** | A swappable mechanism added to the robot for a specific run. |
| **Match** | One 2:30 round of the Robot Game. |
| **Dual Lock** | The velcro-like fastener holding mission models to the mat. |
| **Equipment** | Everything the team brings to the table: robot, attachments, hub. Must fit in the launch area at the start. |
| **Core Values** | Discovery, Innovation, Impact, Inclusion, Teamwork, Fun. Judged, not optional. |
| **Gracious Professionalism®** | FIRST's ethic: compete hard, treat everyone well. |
| **Coopertition®** | Helping other teams even while competing against them. |
| **Innovation Project** | The research-and-solve half of the challenge, on the season's theme. |
| **Engineering Notebook** | The team's documented journey, submitted to judges. |
| **Rubric** | The scoring sheet judges use. Read them — they tell you exactly what's rewarded. |
| **Challenge Updates** | Official rule changes published after kickoff. They override the rulebook. |
| **SPIKE Prime** | The LEGO Education robotics platform we're using. |
| **Word Blocks** | SPIKE's drag-and-drop visual programming language. |
| **My Blocks** | Reusable custom blocks — our shared `drive_straight`, `turn_degrees`, etc. |
| **Hub** | The programmable brick with the display and ports. |
| **Gyro** | The hub's built-in orientation sensor, used for accurate turns. |

_Add terms as we hit them._
