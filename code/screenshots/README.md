Screenshots of Word Blocks programs.

One PNG per program, named to match the `.llsp3` file:
`R2-cargo-line.llsp3` → `R2-cargo-line.png`

If the block stack is too tall for one screen, number them:
`R2-cargo-line-1.png`, `R2-cargo-line-2.png`.

These are how the team reviews code changes, and they go straight into the
Engineering Notebook.
