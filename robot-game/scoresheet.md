Mirrors the official referee scoresheet line for line, so practice scoring matches
match scoring. Print one per practice match.

Four different files in this repo ask for attempt data. To settle it: **the run files
own attempt-by-attempt reliability, and this page owns whole-match scores.** If a
number could go in either, it goes in the run file.

## Things the real sheet does that are easy to forget

**The team signs it.** The official sheet has a "TEAM INITIALS" field. The referee
walks through the result with you and it becomes official when you agree. So read it,
and query anything that looks wrong — unclear calls go to the team.

**Inspection is recorded before the match**, not after.

**The dock choice for M15 is written on the sheet.** It is a declared decision, not
something you adjust once you see how the run is going.

**M04 has three lines, not two.** Leaves counted, katydid in the habitat, and then
the bonus for the katydid never having moved. Getting a leaf out but knocking the
katydid loose is a real and expensive outcome.

**M05 is a three-way choice**, not two rows — No, Partially, Completely.
