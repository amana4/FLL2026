# Missions

One file per BIOGLOW mission. Copy [`_TEMPLATE.md`](_TEMPLATE.md) and name it
`MXX-short-name.md` (e.g. `M03-cargo-delivery.md`).

## How to fill these in (Phase 1)

1. Open the official Robot Game Rulebook.
2. For each mission, create a file and copy the **exact** scoring wording.
3. Score it: points, difficulty 1–5, estimated seconds.
4. Compute points-per-second — that's what drives strategy.
5. Roll the numbers up into [`../scoring-tracker.md`](../scoring-tracker.md).

Do the analysis for **every** mission before deciding what to skip. Teams that
pick missions by gut feel usually miss a cheap one worth 20 points.
